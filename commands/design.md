# Game Studio - Design Phase

You are now in **Design Phase**. Focus on creating comprehensive documentation before any development begins.

## Design Phase Overview

This phase produces all documentation needed to guide development:
- Game Design Document (GDD)
- Art Style Guide
- Technical Architecture
- Feature Specifications
- Market Validation

## Workflow

### Step 1: Market Validation

Before deep design work, validate the concept:

1. **Quick Market Scan**
   - Identify 3-5 similar games
   - Analyze what works and what doesn't
   - Find the market gap your game fills

2. **Target Audience**
   - Define player demographics
   - Understand player motivations
   - Identify spending patterns

3. **Go/No-Go Decision**
   - Is there a market opportunity?
   - Can we differentiate effectively?
   - Is the scope realistic?

### Step 2: Core Design

Develop the foundational design:

1. **Vision & Pillars**
   - One-sentence game description
   - 3-5 design pillars
   - Target player emotions

2. **Core Loop**
   - Primary gameplay cycle
   - What players do moment-to-moment
   - How the loop feels satisfying

3. **Progression**
   - How players improve
   - Unlock systems
   - Long-term engagement hooks

### Step 3: Systems Design

Document each game system:

```markdown
## System: [System Name]

### Purpose
[Why this system exists]

### Player Interaction
[How players engage with it]

### Core Mechanics
- [Mechanic 1]
- [Mechanic 2]

### Parameters
| Parameter | Default | Range | Notes |
|-----------|---------|-------|-------|
| [Param] | [Value] | [Min-Max] | [Purpose] |

### Dependencies
- Requires: [Other systems]
- Provides: [What it enables]

### Success Metrics
- [How we know it works]
```

### Step 4: Content Planning

Define the content scope:

- Levels/stages/worlds
- Characters/enemies
- Items/abilities
- Story elements (if applicable)

### Step 5: Art Direction

Establish visual identity:

1. **Mood Boards**
   - Collect reference images
   - Define the feeling

2. **Color Palette**
   - Primary, secondary, accent colors
   - Usage guidelines

3. **Style Specifications**
   - Character proportions
   - Environment style
   - UI design language

### Step 6: Technical Planning

Outline technical requirements:

- Platform constraints
- Performance targets
- Key technical challenges
- Third-party tools/plugins needed

## Deliverables Checklist

By end of Design Phase, you should have:

- [ ] Complete GDD with all systems documented
- [ ] Art style guide with references
- [ ] Technical architecture outline
- [ ] Feature prioritization (core vs nice-to-have)
- [ ] Milestone plan
- [ ] Risk assessment
- [ ] Market validation report

## Phase Transition

Ready to move to development when:
1. GDD is approved and complete
2. Art direction is defined
3. Technical approach is validated
4. Scope is realistic for resources
5. Risks are identified with mitigations

## Agents for Design Phase

- **game-design**: Lead agent for GDD and systems
- **game-art**: For style guide and visual direction
- **market-intel**: For market validation and analytics planning

## Tips

- Don't over-design - leave room for iteration
- Focus on core experience first
- Get feedback early on key designs
- Document decisions and rationale
- Keep scope realistic
